Shilpa-Vijnana: The Science of Sacred Architecture 🏛️

Shilpa-Vijnana is an interactive web platform designed to decode the advanced engineering, acoustics, and astronomical precision of India's ancient temples through the lens of modern science.

This project bridges the gap between the ancient Indian Knowledge System (IKS) and modern technology, featuring AI-powered tools to enhance the learning experience.

🌟 Key Features

1. Architectural Marvels Showcase

A curated visual journey through India's most significant temples (e.g., Konark, Thanjavur, Ellora), highlighting their engineering feats such as shadow alignments, acoustic pillars, and monolithic construction.

2. Hoysala Architecture Deep Dive

A dedicated section exploring the "Poetry in Stone"—the stellate plans and lathe-turned pillars of the Hoysala dynasty (Belur, Halebidu, Somanathapura).

3. Chronicles of Stone (Interactive Timeline) ⏳

A horizontal scrolling timeline allowing users to traverse different eras of Indian architecture, from the Mauryan period to the Vijayanagara empire.

4. The Sthapati Challenge (Gamified Quiz) 🧠

An interactive 25-question quiz engine that tests users' knowledge of architectural styles, materials, and history with instant feedback and scoring.

5. Shilpa-Kosha (Glossary) 📖

A searchable dictionary of technical architectural terms (e.g., Gopuram, Vimana, Jagati), making complex terminology accessible to everyone.

6. AI Features (Powered by Google Gemini) 🤖

Ask the Sthapati: A context-aware chatbot acting as an expert guide to answer specific questions about temple history and engineering.

Sacred Yatra Planner: An intelligent itinerary generator that creates customized spiritual travel plans based on the user's starting city, duration, and specific interests.

🚀 Getting Started

This project is built as a lightweight, single-file application for ease of deployment and study.

Prerequisites

A modern web browser (Chrome, Edge, Firefox).

An active internet connection (to load CDNs and access the Gemini API).

A Google Gemini API Key.

Installation

Clone the Repository

git clone [https://github.com/yourusername/shilpa-vijnana.git](https://github.com/yourusername/shilpa-vijnana.git)
cd shilpa-vijnana


Configure API Key

Open index.html in a code editor.

Scroll to the bottom <script> section (approx. line 740).

Locate the variable: const apiKey = "YOUR_API_KEY_HERE";

Replace the placeholder with your actual Gemini API key.

Run the Project

Simply double-click index.html to open it in your browser.

Alternatively, use a live server extension (like Live Server in VS Code) for a better development experience.
